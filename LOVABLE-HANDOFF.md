# Briefing para o chat Lovable

**Projeto:** https://lovable.dev/projects/ee862631-ae9a-4471-9930-a7ef07199461

**Referência de código:** https://github.com/ptnagora-byte/NOVAPAGINA

Adapte a página atual usando a versão NOVAPAGINA como referência de layout e copy; preserve as imagens reais do Projeto Fossa Séptica, a integração atual de checkout Kiwify, pixel Meta, UTMs e elementos de identidade visual.

Prioridades:
1. Primeira dobra mobile-first com H1 focado em aprendizado e oportunidade de serviço, H2 com caminho simples, três microbenefícios, foto/capa do material real e CTA que rola para a galeria de páginas do PDF.
2. Oferta transparente: mostre a lista dos seis conteúdos comprovados no guia antes de mostrar o preço de R$27. Apenas o botão no bloco de preço deve abrir o checkout. Manter garantia de 7 dias.
3. Cards de benefícios, de público ideal e prova visual real com imagens do PDF; jamais confundir uma foto ilustrativa com testemunho real.
4. Evitar alegações sem comprovação: não exibir vendas hoje, estrelas ou depoimentos fictícios, desconto sem preço anterior real, contagem dinâmica simulada ou +5 anos de marca se não houver documentação.
5. Adicionar seção "Como você recebe o material" com pagamento Kiwify, liberação após confirmação e acesso digital. Não anunciar bônus inexistentes.

Requisitos: português do Brasil simples e direto, sem prometer renda, responsividade, acessibilidade, carregamento leve, boa leitura no celular, copy curta, rastreamento preservado. Não modifique ou desconfigure o checkout existente. Não publique alterações sem revisar os dados do checkout e conferir imagens.

**Observação:** se o projeto Lovable já estiver conectado a um repositório diferente, faça essas alterações no próprio projeto ou no repositório dele; o link NOVAPAGINA não implica sincronização automática com Lovable.
